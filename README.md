# Student Performance Analyzer

A Python-based data analysis project that analyzes student academic performance using Pandas and Matplotlib.

## Features

- Read student data from CSV
- Calculate individual student averages
- Find the top-performing student
- Calculate subject-wise averages
- Identify the best-performing subject
- Perform Pass/Fail analysis
- Search for individual students
- Generate performance charts

## Technologies Used

- Python
- Pandas
- Matplotlib
- CSV

## How to Run

Install the required libraries:

pip install -r requirements.txt

Run the program:

python src/analyzer.py

## Project Output

The project generates charts showing subject-wise and student-wise performance.
